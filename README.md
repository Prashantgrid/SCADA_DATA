# SCADA_DATA

SCADA inverter datasets and reference PV measurements.

## Original inverter exports

The 18 original inverter exports are stored at the repository root as `1.gz` through `18.gz`, without recompression.

## NIST PV and weather data, 2015–2018

See [NIST_PV_2015_2018](NIST_PV_2015_2018/README.md) for the one-minute measurements from the Canopy, Ground and Roof arrays and the two weather-station loggers in Gaithersburg, Maryland, USA.

- 20 original annual ZIP archives, approximately 1.15 GB in total.
- Inverter temperatures, AC/DC power, electrical measurements, irradiance and weather channels.
- NIST documentation, checksums, column headers and a file-level coverage inventory.
- Roof data for 2018 end on 18 March; other missing daily files are listed in the inventory.

Dataset DOI: https://doi.org/10.18434/M3S67G

The NIST data are a separate reference dataset and are not measurements from the plant in the original inverter exports.
